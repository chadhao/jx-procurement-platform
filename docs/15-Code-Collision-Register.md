## 1. 纪律（本表存在的理由）

> ★ **同一 token 只应允许一个含义**。若因历史原因必须共存，则**必须**同时做两件事：
> ① **在两处「双向」加注**（各自点明「对方是哪一个」—— 只写「见对方」＝没写）；② **登记入本表**。
>
> ★ 与 **`R24`**（「同一职能只允许一个入口」）**同源** —— 两者防的都是 **「重名 / 重号 → 走错 → 且走错不报错」** 这一静默模式。
> ★ 与 **`#48` / `#50`** 的分工：`#48` / `#50` 管「位点**是否存在**」；**本表（`#56`）** 管「位点**是否唯一**」。
> ★ **加注不是越多越好**（过度加注会使读者**忽略所有注**）：本表按**「最小加注集」**只对**高危族**加注，其余**只登记** —— 逐族裁定见 **§2「状态」列 ＋ §2.1**。

### 5.2 什么算「碰撞」

一个 `token`（如 `C4`）被判为**碰撞**，当且仅当满足以下**任一**：

1. **同文件内多义**：同一 `token` 在**同一文件内**被用于 **≥2 个不同事物**；
2. **跨文件异义**：同一 `token` 在**两个文件**分别指**不同事物**（即使各自文件内单义）。

★ **不算碰撞**（不登入 §2）：
- **同义引用**：一处**引用**另一处（含义相同）→ 归 **§3 同义指针**；
- **视觉可分的变体**：如 `N-11`（带连字符）vs `N11`、`P01`（补零）vs `P1`、`L01`（补零）vs `L1`、`C-A` vs `C1` —— **字面不同即不同 token**；但**若易混仍在 §2 备注**（★ `L` 族即此例，见 §2 行 10 ＋ §3.1）。

### 5.3 遇到「疑似」怎么判（判据 —— 「先取定义位点、再核引用」）

对任一疑似 `token`，按三步判：

1. **取定义位点**：找该 `token` **被定义处**（通常是**标题**或**表格首列**），记下「**它是谁**」（**定义源文件 ＋ 章节**）。
2. **核每处引用**：逐一取该 `token` 的**每处出现**，判其**指回的定义**是否**同一个** —— 看**上下文动词 / 表头 / 来源标注**，**不看字面相似**。
3. **下判**：
   - 有 **≥2 个不同定义源** → **碰撞** → 登记 **§2**（＋ 若属最小加注集则双向加注）；
   - 只有 **1 个定义源**、其余皆引用 → **同义指针** → 登记 **§3**；
   - **无法判**（作者意图不明）→ **不臆断**，登记为「**待澄清**」并**报 team-lead**。

### 5.4 ★ 可复跑命令（不必相信本表，自己跑）

**① 列出扫描覆盖（应为 19 个文件）：**

```bash
find docs -name '*.md' | sort
```

**② 对任一 `token` 打印全部「文件:行」出现（把 `C4` 换成你关心的 token）：**

```bash
grep -rn 'C4' docs --include='*.md'
```

> ★ 若噪声多，可再管一道 `grep -v`**排除同前缀的复合编号**（按需增删），例如排除 `FR-`/`M…-…` 形态：
> `grep -rn 'C4' docs --include='*.md' | grep -v -E 'FR-|M[0-9]+-'`

**③ 全族一次扫（按「前导非字母 / 数字 / 连字符」界定**裸 token**，避免误吞 `FR-M0-09` / `B46` / `x-A1`）：**

```bash
python - <<'PY'
import re, glob
files = sorted(glob.glob('docs/**/*.md', recursive=True))
print("scanned .md files:", len(files))
pat = re.compile(r'(?<![A-Za-z0-9_\-])([A-Z])(\d{1,2})(?![0-9])')
for f in files:
    for i, line in enumerate(open(f, encoding='utf-8'), 1):
        for m in pat.finditer(line):
            print(f"{f}:{i}: {m.group(0)}")
PY
```

> 把输出**按 `token` 分组**，逐组套 **§5.3** 三步判，即可**独立复现** §2 / §3 的登记结论。★ 上式为**示意**；界定的关键是「前导 / 后继字符」正则 —— 改口径即须同步改本式，**勿只改结论不改判据**。
