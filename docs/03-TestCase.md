# 采购与费用审批平台（自建侧）· 测试用例

> 结论先行：★ **架构转向 ③ 后，审批流转搬到我方** —— 测试重心随之变为三块：**① 我方审批状态机的正确性（四操作 / 顺序会签 / 终态锁号）**、**② 与飞书三方审批接口的「收 / 发是否可靠且不静默」（回调落盘即 200 / 推送幂等 / 对账方向判断）**、**③ 分权是否真的拦得住**。飞书侧只保留「展示 / 待办 / 通知 + **同意 / 拒绝** 两键」（其按钮是否显示、待办文案**不在本系统测试范围**）；集团侧付款流程仍全人工。

> ★ **本文已按转向 ③ 收口（V1.12）**：**作废 5 条**（`TC-01` / `TC-02` / `TC-08` / `TC-25` / `TC-43`，均**写明作废理由**、原文留痕不执行）· **改造 11 条**（`TC-03` / `TC-05` / `TC-16` / `TC-22` / `TC-30` / `TC-42` / `TC-44` / `TC-46` / `TC-57` / `TC-58` / `TC-59`）· **新增 11 条**（`TC-71` ~ `TC-81`）。依据：`01a §10.3` · `11 §8.3` · `04a §12`。
