| # | 定案 | 依据 |
|---|---|---|
| 1 | **幂等键 = 事件级唯一 ID**（2.0 版 `header.event_id` / 1.0 版 `uuid`）；**不是** `instance_code + status` | 飞书《事件概述》官方原文；`instance_code + status` 会吞掉驳回重提的第二次 PENDING。★ **③ 后作废**：事件源由「飞书推送事件」改为「**入站回调**」，幂等键随之改为**回调幂等键**（`01-PRD` **Q17 改写**） |
