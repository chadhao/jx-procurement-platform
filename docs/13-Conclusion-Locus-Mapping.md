## 3. 位点判据（我的补充建议，供 team-lead 采纳）

1. **位点必须"三段可核"**：`文件` + `章节 / 锚点` + `动作动词`（新增 / 改写 / 标注作废 / 删除）。**只写前两段仍会漏改**。
2. **每个位点须由"非作者"能独立判定"改没改"**：应能靠检索命中（如"`04a` 中出现『部署与入网』节"）→ 建议派单时附**可核验断言**。
3. **归属应写"某文件的作者"而非"某人"**：避免"我以为别人改"。
4. **新增文档必须先给编号**：如 A-7 的 runbook，应先定其文档编号再派单（否则又是"无位点"）。
5. **审计 / 评估报告自身的每条结论也要有位点**：至少落一个"被执行文档的章节"；否则报告会退化为"读完即忘"。
